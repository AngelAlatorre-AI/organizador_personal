# Recomendaciones de mejora

1. Agregar pruebas automatizadas para verificar que las funciones principales del proyecto funcionen correctamente y evitar errores después de realizar cambios.

2. Organizar el proyecto en carpetas según su función, por ejemplo, separar el código fuente, la documentación, las pruebas y los recursos. Esto facilita el mantenimiento y la colaboración entre integrantes.

3. Mejorar la documentación del `README.md` agregando los requisitos, pasos de instalación, forma de uso y ejemplos de ejecución del proyecto.
